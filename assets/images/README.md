# Images

Drop exported images straight into this folder. Nothing needs to be
registered anywhere — the HTML references files by path.

## Naming

Use lowercase, hyphenated, descriptive names. The placeholders in the HTML
already reference these:

| Filename                        | Used on              | Aspect | Export size |
| ------------------------------- | -------------------- | ------ | ----------- |
| `ian-hero.webp`                 | `/about/`            | 4:5    | 1200 × 1500 |
| `ian-physique-front.webp`       | `/` and `/bodybuilding/` | 4:5 | 1200 × 1500 |
| `ian-physique-back.webp`        | `/bodybuilding/`     | 4:5    | 1200 × 1500 |
| `ian-physique-side.webp`        | `/bodybuilding/`     | 4:5    | 1200 × 1500 |
| `ian-technology-workspace.webp` | reserved             | 3:2    | 1800 × 1200 |
| `og-default.png`                | social preview       | 1.91:1 | 1200 × 630  |

## Format and size

- **WebP** for photography. Quality 78–85 is usually indistinguishable from
  the original at these dimensions.
- **PNG** only for the Open Graph image (some scrapers still handle WebP
  poorly) and for flat graphics.
- **SVG** for anything vector.
- Keep each photograph **under ~250 KB**. Above that, drop quality before
  dropping dimensions.
- Export at roughly **2× the largest rendered size**, then stop. The gallery
  renders at about 380 px wide on a large desktop, so 1200 px is already
  generous.

## Replacing a placeholder

Find the placeholder block in the HTML:

```html
<div class="media media--portrait">
  <div class="media__placeholder">…</div>
</div>
```

Replace the inner `div` with a real image and keep the wrapper, so the
reserved aspect ratio prevents layout shift:

```html
<div class="media media--portrait">
  <img src="/assets/images/ian-physique-front.webp"
       alt="Ian Vulovic, front relaxed pose"
       width="1200" height="1500"
       loading="lazy" decoding="async">
</div>
```

Always set `width` and `height` (the intrinsic pixel size) and write real
`alt` text. Use `loading="lazy"` for everything except an image that is
visible before scrolling.

## Serving multiple sizes later

When it becomes worth it, export a 600 px and 1200 px version and switch to
`srcset` — no CSS changes needed:

```html
<img src="/assets/images/ian-physique-front-1200.webp"
     srcset="/assets/images/ian-physique-front-600.webp 600w,
             /assets/images/ian-physique-front-1200.webp 1200w"
     sizes="(min-width: 56.25em) 33vw, 100vw"
     alt="…" width="1200" height="1500" loading="lazy" decoding="async">
```

## Strip EXIF before publishing

Phone photos carry GPS coordinates, timestamps and device serials. On the
family page in particular, one geotagged image undoes the point of leaving
the location out.

Most WebP exporters drop EXIF automatically, but verify rather than assume:

```bash
exiftool -all= -overwrite_original assets/images/*.webp
```

Then confirm nothing is left:

```bash
exiftool -gps:all -make -model assets/images/family-01.webp
```

## Regenerating the Open Graph image

`og-default.png` was generated by a small script kept outside the repo. The
simplest way to change it is to edit the PNG directly, or re-export a
1200 × 630 image with the same name. Its contents are referenced by the
`og:image` meta tag on every page.
